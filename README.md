### SAN値コマンド
  
  手軽に正気度ロール(SAN値チェック)が行えます。
  <br>
  送信例:
  ```
  探索者たちは、おぞましい物を見た
  SAN値チェック1d10/1d100
  @MT
  ```

  返信例:
  ```
  @MT
  CCB<=60 (1D100<=60) > 30 > 成功

  1D10 > 8

  SAN値: 60 -> 52
  ```


<details>
  <summary>使い方の詳細</summary>

#### 使い方
```
SAN値チェック{減少量} {対象}
```
を送信するだけです。

#### {減少量}
成功時と失敗時を/でわけてください。
定数でも可能です。1d3などとダイスロールで減少量を変える事も可能です。

#### {対象}
メンションで明示しても構いません。
省略すると送信者がSAN値チェックを行い。
明示する場合は、明示された方のみがSAN値チェックを行います。

</details>

### !help
ヘルプコマンドです。

### !roll
  ダイスロールを振ることができます。
  <br>
  BCdice APIを使用しています。
  <br>
  また、友達追加しているとシークレットダイスが振れるようになります。
  
  送信例:
  ```
  !roll CCB<=30 精神分析(物理)
  ```

  返信例:
  ```
  CCB<=30 精神分析(物理)
  (1D100<=30) ＞ 79 ＞ 失敗
  ```
### !all
SAN値チェックに参加してるメンバーを確認することができます。
<br>
送信例:
```
!all
```

返信例:
```
@A
@B
@C
```

### !reset
自分のSAN値を初期値の60に戻すことができます。
<br>
送信例:
```
!reset
```

返信例:
```
@MT

SAN値: 15 -> 60
```
